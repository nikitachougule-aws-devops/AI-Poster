# Vardhaman Agro Marathi Poster Maker

A starter Streamlit app for creating a customizable Marathi product poster.

## Files
- `app.py`: Streamlit UI and poster renderer
- `requirements.txt`: Python packages
- `packages.txt`: Linux package for Noto fonts

## Deploy to Streamlit Community Cloud
1. Create a GitHub repository.
2. Upload these three files to the repository root.
3. Open https://share.streamlit.io/ and choose **Create app**.
4. Select your repository, branch (`main`), and `app.py`.
5. Deploy. Community Cloud installs packages listed in `requirements.txt` and `packages.txt`.
6. Edit the sidebar text, upload the actual logo and product photos, then generate and download the PNG.

## Print note
The output canvas is 1800 x 2700 px (2:3 ratio). Before roadside printing, ask the print shop to confirm final physical size, resolution, colour profile and bleed. The app is a starter template; check all Marathi text, spelling, address, email and phone numbers before printing.
